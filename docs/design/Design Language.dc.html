PHOSPHOR · DESIGN LANGUAGE v0.2
Everything is cells, color is meaning, floats are the only chrome
Codified from the seven mockup turns, written for a ratatui component breakdown. Three laws: the character grid is the only layout unit; each color names exactly one actor or state, never decoration; every surface is either the buffer, the statusline, or a float — nothing else exists.
1 · Color — one hue per actor
#3ddc97claude — his edits, his marks, his voice #82aecdyou — insert mode, your side of diffs, watches #e0a94eattention — waiting, paused, dirty, permission #d97b6ctrouble — deletions, failures, disconnects #cfa86atransient — visual mode, spinners, types #9ec98csteel — repl, functions, scripting
Neutrals: #0c0f0c ground, #c6cec6 text, #9aa39a prose, #59635a meta, #414b42 line nums, #232823 dimmed-under-float. Rule: green always means claude; a green pixel with another meaning is a bug. Ships as a base16-style theme so terminals can restyle it.
2 · Glyph lexicon — one cell, one concept
✻claude, and anything he produced ⠸working — braille spinner, animates !needs you — question or permission ⏸ ✱paused · changed-on-disk ✕ ■session lost · diagnostic ●unseen count (files, inbox) ⚓ ┊anchor · virtual-text margin rail ◉ ⇒watch · value stream ▸ ▾ ⋯fold closed · open · elided λ ◆steel prompt · steel surface
All single-cell, Nerd-Font-free, present in default terminal fonts. Spinner frames: ⠋⠙⠸⠴⠦⠇.
3 · The gutter — 3 columns, fixed contract
17unseen — claude wrote, you haven't looked
18seen — marker cleared, line is plain
19diagnostic region
20anchored region — tint + undercurl
┊ virtual text hangs from its region
Column 1: the 1-cell state bar (unseen/diagnostic/none — priority: trouble > attention > claude). Column 2: line numbers, always #414b42. Column 3: text. Region highlights tint the whole row (#141d16 anchor, #26332a selection-in-float, #211114 failure). Virtual text indents to code column, prefixed ┊, meta-gray with colored spans.
4 · Float anatomy — header · body · keymap
header — source or command · meta right
body — list, diff, prose, or grid
selection row gets  #26332a + bright text 
footer — every legal key, always visible
One border style; border color is the float's mood: #2a5c44 informational, #6b5426 needs-you (body #171207), #2a3c2e passive (completion — no footer, the exception). Background under a float dims code to #232823. No shadows, no rounded corners beyond the terminal's cell, no titlebars. Digits [1] [2] [3] are amber and reserved for answers to claude.
5 · Chrome — tab bar, statusline, tmux; nothing else
src/retry.rs ●3src/fetch.rs ●3transcript3 panes
NORMALsrc/retry.rs [+]✻ claude idle6 unseen │ jj ✓ │ 12:1
PAUSEDsrc/ws/reconnect.rs⏸ claude paused2 unseen
INSERTsrc/fetch.rs [+]✕ session lost — :reattach31:34
[main] 0:te* 1:shell 2:logshost │ 14:32
Three strips of chrome, ever: tab bar (top, appears only with 2+ panes — vim-style but flat: active tab carries a 2px actor-colored top rule and bright text, inactive tabs are meta-gray, unseen counts ride each tab), statusline (bottom, always), and tmux below it, untouched. Statusline left→right: mode chip (bg = mode color, the only inverted text on screen), file + dirty flag, spring, session state, counters. Segments join with a thin bar │ in meta-gray. Statusline content is priority-ordered and truncates from the right — it never wraps; a second line is a bug. Session state is always present and truthful — idle, working+elapsed, waiting, paused, lost. Trouble on the statusline never blocks editing.
6 · Voice — how the editor talks
Lowercase, telegraphic, factual. "connection lost mid-turn · 14:47" — never "Oops! Something went wrong."
Separators carry structure: thin bar │ between statusline segments, midline dot · only inside a fact ("2 files · 6 regions"), em dash for cause ("session lost — :reattach"). Timestamps absolute (14:32) in transcripts, relative (2m) in threads.
Claude speaks in first person, one line. His prose is #9aa39a; facts he produced (diffs, counts) are colored data, not prose.
Counts everywhere: "2 files · 6 regions", "+11 −18", "33 passed · 1 failed". A number beats an adjective.
Keyhints spell the whole command: "s mark seen", ":reattach", ":transcript", ":diff-disk" — never cryptic contractions like :ca or :rr. Abbreviations exist for typing (vim-style unique-prefix matching); the UI always teaches the full name. Footer order: primary action first, escape last.
7 · Region lifecycle — the one state machine
claude writes ──▶ unseen ──s──▶ seen
│ │
│ claude revises the region
│ ▼
◀────────── unseen again
overlays, orthogonal: ⚓ thread · ◉ watch · ■ diagnostic
Seen-state is the only mutable flag the user owns; everything else is derived. Overlays bind to the tree-sitter node, not the state — a seen region keeps its thread. Your own edits never create regions: the machine tracks claude only. Persisted to disk with undo history.
8 · Density & motion — cells, not pixels
Spacing unit is the cell. Float padding: 1 row / 2 cols. Floats span 60–80% of width, centered, never within 4 cols of an edge. Virtual text indents to the code column.
Three strips of chrome: tab bar 1 row (only with 2+ panes), statusline 1 row, tmux bar 1 row. No surface is ever taller than its content.
Only three things animate: the ⠸ spinner (80ms/frame), elapsed timers (1s), and streaming transcript text. Everything else snaps — no easing, no fades. Terminal motion is information, never polish.
Synchronized output wraps every frame; a torn frame is a P0 bug. Degrade on dumb terminals: markers become ▎, undercurl becomes underline, spinner becomes a static ✻.
9 · Focus & layering — one float, one stack
At most one float has focus. Opening a second replaces the first; esc closes top-down. There is no float-over-float, ever.
Needs-you never steals focus. Questions and permission asks appear, set the statusline flag, and wait. Keystrokes go where they went before the float appeared.
The transcript is a pane, not a float — it splits, holds focus like a window, and survives float churn. Panes: buffer, transcript, claude-built (v1.5). Floats: everything else.
Dimming means "behind." Code under a float renders at #232823; panes never dim each other.
10 · Theme — phosphor is default, hue is the contract
Phosphor (dark + light) ships as the v1 default — green-tinted near-black with phosphor green for claude; warm paper with deepened hues in light. Claude owns the brightest color on screen.
Themes are base16-style mappings; Catppuccin and Ayu ship first. A theme owns lightness and syntax colors; it never owns actor identity — claude stays green, attention stays warm, trouble stays red in every mapping.
Light variants deepen, dark variants brighten: claude-green is #3ddc97 on dark, #1a9a62 on light — same hue, contrast-corrected. A theme where green means anything else is rejected, not themed.
11 · Degradation & scale
Narrow terminals drop, never squeeze. Statusline shed order: counters → jj → cursor pos → session prose (glyph stays) → mode word (initial stays). The ✻/●n pair is the last thing standing. Pickers lose the preview split under 100 cols; floats go full-width. Nothing ever wraps.
Scale is grouping, not scrolling. Large review blocks fold by directory; claude annotates groups ("mechanical" vs "the meat"); s / S compose over any group. Transcripts fold by turn the same way.
First keystroke teaches once: unknown key in NORMAL → one virtual-text line naming SPC and :help, once per session, never again.

Reading order for implementation: theme → BufferView → StatusLine → Float/Picker → TranscriptPane → PromptLine. Everything else composes from these. Architecture note: widgets are pure renderers over a ViewModel derived from the semantic store — no widget owns state; input maps key → Action, Actions mutate the store, the store re-derives. That's what makes the same surfaces scriptable from Steel and, in v1.5, from claude.
